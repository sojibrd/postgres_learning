# guide — source and licence

The 31 rule files in this folder, and `_sections.md`, are an unmodified copy of the
`references/` folder of the **supabase-postgres-best-practices** agent skill
(version 1.1.1).

- **Upstream:** https://github.com/supabase/agent-skills — `skills/supabase-postgres-best-practices/`
- **Author:** Supabase — as declared in the skill's `SKILL.md`
- **Licence:** MIT — declared both in the skill's `SKILL.md` (`license: MIT`) and as
  the repository licence reported by the GitHub API on 2026-10-12.
- **Copied:** 2026-10-12, from upstream commit `c9be0e9` (dated 2026-10-02).

Nothing here is written by the owner of this repository. The day-by-day plan in
`docs/` and the site code are separate work and only quote rule titles.

The rules cover PostgreSQL only and name no Postgres version. Each rule ends with a
`Reference:` link; what was checked about those links, and when, is recorded in
`docs/00-rules.md`, not here.

Do not edit these files. A rule that changes upstream is replaced by a fresh copy,
so the text on the site always matches the source.

`_template.md` and `_contributing.md` from the source are left out — they are
instructions for rule authors, not rules. `_sections.md` still carries the source's
own note that its examples are placeholders; the section headings themselves are
the real ones.
